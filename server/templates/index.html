Custom CLI 远程烧录

EIDE 烧录器选择 Custom CLI，将对应命令填入烧录配置。

Windows
python "${ProjectRoot}/Debug_LAN/jlink_flash.py" --program "${programFile}"
Linux
python3 "${ProjectRoot}/Debug_LAN/jlink_flash.py" --program "${programFile}"

先将 Debug_LAN 工具包和下载的配置保存到客户端工程。此配置用于 EIDE 单独烧录；F5 调试仍选择 Debug: JLINK LAN。不要选择全片擦除，工具未配置该命令。

客户端连接配置

高级设置 接口与速度

用于工程烧录与调试；网页 RTT 沿用服务端设置。连接不稳定可降至 4000 或 1000。

Debug_LAN/remote-jlink.json

下载后保存到客户端工程的 Debug_LAN/remote-jlink.json。launch.json 仍需手动核对芯片、ELF 与 SVD 路径；首次接入请合并工具包的 vscode/ 示例，F5 选择 Debug: JLINK LAN。已有自定义 JLinkExe 路径请保留。
